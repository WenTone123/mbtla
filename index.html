MBTLA

Multi-Branch Temporal Linear Attention with Adaptive Retention Gate
Lightweight Causal Speech Enhancement

Overview

MBTLA is a lightweight causal speech enhancement model based on fixed-resolution temporal Linear Attention with adaptive retention. The model introduces multi-branch temporal modeling and content-dependent memory control for efficient speech enhancement.

This page provides audio and spectrogram comparisons with several lightweight speech enhancement baselines.
